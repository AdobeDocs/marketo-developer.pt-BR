# Sandbox de parceiros

Uma sandbox de parceiro é uma instância do Marketo Engage que os parceiros usam durante o ciclo de vida do desenvolvimento de software. Os parceiros podem usar uma sandbox para explorar a interface do usuário do Marketo Engage e acessar os serviços de API da Marketo Engage.

A Adobe fornece uma sandbox depois que um parceiro é aceito no [Programa de parceiro da Adobe Exchange, Experiência digital](https://partners.adobe.com/technologyprogram/experiencecloud.html).

Na maioria dos aspectos, uma sandbox de parceiro é funcionalmente equivalente a uma instância de produção. No entanto, as sandboxes de parceiros não incluem módulos complementares e têm limites de capacidade fixos.

## Resumo de recursos

- Sandboxes: uma por parceiro
- Chamadas de API: 50.000 por dia
- Registros do banco de dados de clientes potenciais: 10.000
- Envios de email: 30 por execução de campanha
- Objetos personalizados: dois
- Usuários: 25
